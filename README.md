# Quantum Feature Map Visualizer

## What This Project Does
- Takes simple 2D points from easy datasets (grids, circles, or moons).
- Encodes those points into quantum states using different quantum feature maps.
- Visualizes how similarity between points changes after the quantum encoding by plotting kernel heatmaps.
- Helps beginners see why quantum kernels might reveal patterns that are hard to spot in the original space.

## Why Quantum Feature Maps Matter
- They transform data into a high-dimensional quantum space.
- They can reveal new patterns or separations without hand-crafted classical features.
- They power quantum kernel methods and many quantum machine learning models.
- They offer intuition about how entanglement mixes information from multiple features.

## Why SVG Instead of PNG
GitHub’s CODEX interface cannot preview binary image files like PNG or JPG and often shows “Binary files are not supported” in pull requests. To avoid this, all visualizations in this repository are saved as lightweight SVG (vector) images. SVGs are text-based, easy to diff, and render cleanly inside GitHub and CODEX.

## Repository Structure
- `app/` – Python package with dataset helpers, feature map builders, embedding utilities, visualization helpers, and the CLI entrypoint.
- `notebooks/` – Jupyter notebook tutorial showing the feature map workflow end-to-end.
- `examples/` – Saved SVG plots generated by the code so you can preview results quickly.
- `tests/` – Lightweight pytest suite to check that datasets, feature maps, and kernels behave as expected.

## How to Run
```bash
pip install -r requirements.txt
python app/main.py --feature-map angle_encoding
python app/main.py --feature-map zz --dataset circles --n-points 40
```
SVG outputs are stored in the `examples/` directory with names that match the feature map and dataset.

## How to Use the Notebook
```bash
jupyter notebook notebooks/feature_map_visualization_demo.ipynb
```
The notebook uses `%config InlineBackend.figure_formats = ['svg']` so that inline plots stay in SVG format.
